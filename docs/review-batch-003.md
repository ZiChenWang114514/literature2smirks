# 源文献核对批次 003

范围：PDF 第 96–115 页，印刷页 42–61；覆盖 KCC021–KCC030。

本批次逐页读取并渲染了 Barton nitrite ester、Barton radical decarboxylation、Barton–McCombie、Baylis–Hillman、Beckmann、Benzilic acid、Benzoin、Bergman cycloaromatization、Biginelli 和 Birch reduction。反应图中的关键边界已经记录：

- Barton 系列依赖自由基、远程 C–H 抽取、脱羧或脱氧，不能用普通局部取代规则替代；
- Baylis–Hillman 是活化烯烃、醛和亲核催化剂的多组分成键过程，催化剂和速率限制不进入图变换本身；
- Biginelli 是醛、尿素和 β-酮酯的三组分环化，Atwal 变体应作为独立模式；
- Birch reduction 的区域选择性由 EDG/EWG 和质子源决定，不能仅用“芳环变成二烯”模板表达完整适用性。

这些条目已纳入全书索引和源页证据定位；仍需从图式逐一恢复具体原子映射后，才能进入 `source_transcribed`。
